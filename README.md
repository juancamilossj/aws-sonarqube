# 🧠 SynapseEdu | Red Neuronal Cognitiva Interdisciplinaria

Una plataforma interactiva de última generación construida con **Node.js**, **React** y **Tailwind CSS**, diseñada para transformar el aprendizaje y la gestión curricular en instituciones educativas mediante **redes neuronales y nodos holográficos interactivos**.

---

## 🎯 Problemática Educativa que Resuelve

### 1. Silos Disciplinares y Desconexión Curricular
En la educación tradicional, las asignaturas se enseñan de forma aislada (matemáticas por un lado, computación por otro, filosofía y bioética por otro). Los estudiantes no perciben la profunda interdependencia entre estos campos y pierden la motivación al no comprender la utilidad práctica u holística del conocimiento.

### 2. Bloqueos Cognitivos Invisibles y Rezago Sistémico
Cuando un estudiante reprueba o se estanca en una materia avanzada (por ejemplo, *Descenso de Gradiente* o *Transformers*), la causa real suele ser una laguna conceptual en temas fundamentales que cursó hace meses (como *Álgebra Lineal* o *Cálculo Multivariable*). Los docentes y directivos carecen de un mapa en tiempo real que trace el origen exacto del rezago académico en una cohorte.

---

## ⚡ La Solución: SynapseEdu (NeuroLearn Nexus)

**SynapseEdu** modela todo el plan de estudios como un **Cerebro Vivo (Conectoma)**:

1. **Neuronas Holográficas (Nodos)**: Cada nodo representa una competencia o concepto clave, con su nivel cognitivo, estado de dominio (Dominado, En Proceso, Bloqueado), resumen epistemológico y laboratorios interactivos (*Holo-Labs*).
2. **Sinapsis y Potenciales de Acción (Axones)**: Enlaces dinámicos que muestran cómo fluye el conocimiento. Destacan partículas de luz que viajan en tiempo real simbolizando la transferencia de información.
3. **Puentes Interdisciplinarios**: Conexiones de alta energía que vinculan áreas aparentemente distantes (ej. Álgebra Lineal con Redes Neuronales y Mecánica Cuántica; Neurobiología con Interfaces Cerebro-Máquina y Neuroderechos).
4. **Doble Experiencia de Usuario**:
   - 🎓 **Modo Estudiante**: Exploración interactiva del mapa, desafíos diagnósticos para disparar potenciales de acción y desbloquear ramas superiores, seguimiento de Neuro-XP, rangos y racha sináptica.
   - 🔬 **Modo Docente (Telemetría Institucional)**: Monitoreo en tiempo real de la salud del conectoma de la cohorte, detección instantánea de **Cuellos de Botella Cognitivos** (nodos con alto índice de rezago y recomendación de causa raíz), e inyección en caliente de nuevas neuronas y sinapsis curriculares.
5. **Inmersión Auditiva Neural**: Sintetizador de audio procedural basado en la *Web Audio API* nativa que emite impulsos sinápticos, pulsos armónicos de activación y tonos de alerta sin dependencias de archivos externos.

---

## 🛠️ Stack Tecnológico

- **Backend**: Node.js, Express, CORS, Base de datos JSON reactiva con recálculo automático de prerrequisitos.
- **Frontend**: React (Vite), Tailwind CSS (estilo futurista/cyberpunk), Lucide Icons, Canvas Confetti.
- **Visualizador Gráfico**: Motor HTML5 Canvas de 60 FPS con física de partículas, cámara orbital (pan & zoom continuo), halos radiantes y trazo de sinapsis curvas.
- **Audio Engine**: Sintetizador Web Audio API procedural integrado.

## 🚀 Puesta en Marcha Rápida

### Prerrequisitos
- Node.js (v18 o superior)
- npm

### 1. Iniciar con un solo comando (Desarrollo)
En la raíz del proyecto ejecuta:
```bash
npm run dev
```
Esto iniciará concurrentemente:
- El servidor backend en: `http://localhost:4000`
- El cliente interactivo Vite en: `http://localhost:3000`

### 2. Ejecución Integrada (Producción / Demostración)
Para compilar y correr todo servido directamente desde Node.js:
```bash
npm run build
npm start
```
Luego abre tu navegador en:
👉 `http://localhost:4000`

## 🎮 Guía de Interacción

- **Navegación en el Conectoma**:
  - Arrastra con el mouse cualquier espacio libre para mover la cámara (Pan).
  - Usa la rueda del mouse o los botones flotantes (+ / -) para hacer Zoom.
  - Haz clic y arrastra cualquier neurona para reorganizar el mapa mental.
  - Pasa el cursor sobre un nodo para iluminar sus rutas de prerrequisitos y dependencias.
- **Activación de Neuronas**:
  - Haz clic en cualquier nodo para abrir la terminal neuronal.
  - Resuelve el *Desafío de Activación* para ganar Neuro-XP y desbloquear las neuronas subsiguientes.
- **Cambio de Modo (Estudiante / Docente)**:
  - Usa el conmutador superior para alternar entre la vista de aprendizaje y el panel de telemetría institucional.
  - En modo docente, haz clic en cualquier cuello de botella para enfocar la causa raíz del rezago o usa `+ Neurona` / `+ Sinapsis` para expandir el currículo.
